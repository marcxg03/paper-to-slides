# Irrational Labs deck style

Reference: `il-example-deck.pdf` and `il-example-slide-1…5.png` (IL's example deck on Chang, Kirgios, Mullainathan & Milkman, 2024). Match this look.

## Format
16:9. 3–5 slides. Lots of white space. One idea per slide.

## Type
| Role | Font | Size | Notes |
|---|---|---|---|
| Headline | **Oswald** SemiBold | ~30 pt | condensed, bold, sentence case; a takeaway or a question |
| Body | **Proxima Nova** (use **Figtree** or Montserrat if unavailable) | 15–25 pt | short sentences; bold the key phrase inline |
| Source line | body font | ~8 pt, gray `#888888` | bottom-right on every content slide |
| Footnote | body font | ~8 pt | plain-words stats, e.g. "* p < 0.001 (statistically significant)" |

## Color
| Token | Hex | Use |
|---|---|---|
| IL blue | `#016DB6` | full-bleed title panel; setup slides |
| Chart blue | `#266DB0` | comparison bar and label |
| Navy text | `#0B4A7E` (approx.) | headlines/body on light slides |
| Light blue panel | `#DBEAF4` | half-slide background (setup slides) |
| IL orange-red | `#EC5431` | result headline, highlighted bar, emphasis |
| Peach panel | `#FBE3DD` | half-slide background (result slides) |
| Muted gray-blue | `#9FB2BF` | de-emphasized elements |
| White | `#FFFFFF` | base |

Each slide uses one color family: **blue for concept and setup, orange-red for the result and what follows.** The color shift marks the move from setup to finding.

## Layout patterns
- **Half-panel split:** one half a solid pastel or brand-color block, text on one side, the visual on the other.
- **Hand-drawn line illustrations** and simple line icons; at most one hero illustration (slide 1).
- **Charts:** plain bars, light gridlines, very large colored data labels (Oswald) above the bars, a dot legend, the axis labelled in plain words.
- **Logo:** `il-logo.png` bottom-left on every slide, tinted to the slide's color (white on IL blue).

## Voice
Talk to the audience in the second person ("You're planning a vacation…"). Let them *experience* the effect before naming it when the study allows it (IL's slides 2–3). Titles are takeaways, not topic labels.

## IL's example arc (for reference, not a template)
1. Concept: name + one-sentence plain definition + illustration
2. Scenario: the audience makes the study's choice themselves
3. Twist: the same choice, re-presented with the manipulation
4. Result: one takeaway headline, one sentence, one 2-bar chart
5. Robustness: "What if…" → "The results still hold!"

Our decks must also include **product implications**, which IL's example doesn't show. Give them their own slide in the same style.
